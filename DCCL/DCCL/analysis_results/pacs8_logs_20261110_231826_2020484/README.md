# PACS: text/LR four runs and contrastive four runs

Eight configurations, each with four held-out target domains, steps 0..300, check=10.
Each results.jsonl has exactly 124 valid validation records plus a completed log summary.
Source paths and record hashes are in manifest.json. Incomplete runs are excluded.
No model checkpoints, TensorBoard files or VLCS results are included.
collection_git_state.txt records repository state at collection, not necessarily training time.
